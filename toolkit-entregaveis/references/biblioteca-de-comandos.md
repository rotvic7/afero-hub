# Biblioteca de comandos

## Diagnosticar

```text
Use $toolkit-entregaveis. Leia modelo-de-produto.md e conteudo-do-produto.md. Liste campos essenciais ausentes, aplique os critérios de formato e devolva uma recomendação com capacidades incluídas, excluídas, riscos e critério de aceite. Pare antes de construir.
```

## Criar a primeira versão

```text
Use $toolkit-entregaveis. Leia as duas entradas do produto, confirme que estão completas e apresente o escopo mínimo do formato recomendado. Depois da minha aprovação, construa a primeira versão e valide o fluxo principal.
```

## Revisar um entregável existente

```text
Use $toolkit-entregaveis para revisar o entregável atual. Compare requisitos, conteúdo, formato e manutenção. Identifique até três problemas que afetam uso ou percepção de valor. Proponha mudanças cirúrgicas e aguarde aprovação antes de alterar arquivos.
```

## Evoluir para acesso autenticado

```text
Use $toolkit-entregaveis. Verifique qual requisito novo exige identidade, autorização ou persistência entre dispositivos. Planeje uma migração reversível que preserve conteúdo e experiência atual. Inclua modelo de dados, estados de sessão, recuperação de acesso, testes e estratégia de retorno.
```

## Validar antes da entrega

```text
Use $toolkit-entregaveis somente para validação. Leia controle-de-qualidade.md, execute testes e percorra o fluxo real em navegador quando houver interface. Corrija apenas defeitos necessários para cumprir os critérios aprovados. Informe evidências e limitações.
```

## Preparar publicação

```text
Use $toolkit-entregaveis para preparar a publicação. Execute a suíte final, revise arquivos gerados, variáveis, dados locais, segurança e instruções de operação. Apresente o destino e as mudanças que serão publicadas. Solicite minha autorização antes de qualquer deploy.
```

Primeira importação

Sete passos para alimentar seu Painel.

O guia acompanha o agente e também vive aqui. Abra cada etapa para consultar os comandos enquanto prepara sua primeira caçada.

Fase 01 · Requisitos
01
Verificar se o Python está instalado
Mac + Win ▾

Abre o terminal e roda o comando abaixo. Se aparecer Python 3.x, tá pronto. Se não aparecer, baixa em python.org/downloads.

🍎 Mac
$ python3 --version
🪟 Windows
$ python --version
No Windows, marque a opção "Add python.exe to PATH" durante a instalação, antes de continuar.
02
Criar conta e pegar a API Key do urlscan.io
Config ▾

O agente usa a API pública do urlscan.io pra escanear páginas de venda. A conta é gratuita.

  1. Acessa urlscan.io/user/signup e cria a conta
  2. Confirma o e-mail na caixa de entrada
  3. Vai em urlscan.io/user/profile/
  4. Na seção API Key, copia a chave
Não compartilhe essa chave. Ela dá acesso à sua conta no urlscan.
03
Configurar a API Key no agente
Config ▾

Cria um arquivo chamado urlscan_key.txt na mesma pasta do cacador_ofertas.py, cola a chave dentro e salva. Só a chave, nada mais.

sua-chave-aqui
A chave fica fora do .py de propósito: você atualiza o agente sem perder a configuração, e nunca compartilha a chave junto com o arquivo por engano. Quem preferir variável de ambiente pode usar URLSCAN_API_KEY, que tem prioridade sobre o arquivo.
Fase 02 · Instalação
04
Instalar a dependência
Mac + Win ▾

No terminal, navega até a pasta do cacador_ofertas.py e instala a biblioteca requests.

🍎 Mac
$ pip3 install requests
🪟 Windows
$ pip install requests
Erro de permissão no Mac: use sudo pip3 install requests. Pip não reconhecido no Windows: feche e reabra o terminal depois de instalar o Python.
Fase 03 · Execução
05
Rodar o agente
Mac + Win ▾
🍎 Mac
$ python3 cacador_ofertas.py
🪟 Windows
$ python cacador_ofertas.py

07
Importar a leva aqui no hub
Resultado ▾

O resultado da caçada entra direto no Painel, sem exigir uma planilha intermediária.

  1. Abre a pasta cacada_ofertas/ gerada
  2. Pegue _INFOPRODUTOS_BR.csv ou um dos arquivos SaaS mais recentes
  3. Abra a aba Painel e solte o arquivo na zona de importação
  4. O hub lê tudo em memória e já mostra tier, score e sinais de cada oferta

Descoberta · agente 00

Caçador de Ofertas

Roda 18 buscas cruzadas no registro público do urlscan e monta a fila do que vale modelar. Prioriza a página que carrega gateway e rastreador ao mesmo tempo, porque esse cruzamento é raro e denuncia operação com dinheiro rodando.

Entrada18 queries · 7 gateways, 3 rastreadores, 6 combos ScoreS ≥ 9 · A 6 a 8 · B 3 a 5 · C 0 a 2 Saída_INFOPRODUTOS_BR.csv e SaaS auditado/candidato
Mensagem · agente 01

Agente de Copy

Lê o ângulo da oferta encontrada e devolve a estrutura de resposta direta: big idea, três ganchos alternativos, corpo em PAS ou AIDA, empacotamento de bônus e o script de abordagem para chegar no dono da operação.

Agente de Páginas

Lê a copy aprovada e monta uma página HTML responsiva para preview local. Mantém o vídeo autorizado quando existir referência e deixa os links de checkout vazios até a criação da oferta.
